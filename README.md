# HCM Interview Management Service

## Overview

The **Human Capital Management Interview Service** is a backend application built with **Node.js** and **TypeScript**. It provides a robust API for managing interviews on the platform.

## Features

- Manage Interviews, Report, Attendees and Offers.
- Manage Contract Terms of Engagement.
- Built with **Node.js** and **TypeScript** for type safety and better development experience.
- **Prisma ORM** for database interaction.

---

## Prerequisites

Before running the application, ensure you have the following installed:

- **Node.js** (version 16 or higher)
- **npm** or **yarn**
- A database system like **MySQL** (configured in the `.env` file)

---

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/suburban-fiber-company/HCM_Interview_Management_API.git
cd HCM_Interview_Management_API
```

## Running locally

Starting the application locally, run
